# Snake Game — 設計理念

大家都玩過貪食蛇，就是那條會越吃越長的蛇。但你有沒有想過——如果把「越吃越長」這個規則拿掉，蛇還好不好玩？

這個版本就是從這個問題出發的。每一種模式都偷偷改了一條規則，看看 Snake 能不能變成另一種遊戲。

Speed Survival 不比你多長，比誰心臟夠大顆。分數一高，蛇就快到你來不及想，吃這口會不會死？你自己決定。

CTF 根本不用吃東西，你跟對手搶旗子就好。要進攻還是防守？死掉旗子會噴出來——每一次碰撞都是戰略選擇。

LAN 連線是你跟另一個人類打。電腦很好猜，但人類會騙你。他會在你準備轉彎的地方等你。

Magnet 食物會自己靠過來，好像很輕鬆？但你吃一顆會長出兩顆，永遠追不上進度。

修改器還可以自己打開：方向反轉、地圖穿透、傳送門——你想怎麼玩都行。

## 常見問題

**我的進化版 Snake 改變了原版的哪一個玩法？**

原版 Snake 只有一條規則：吃食物、變長、不要死。贏的唯一方法就是活得比別人久。這個版本把規則拆開了——每一種模式都有自己「贏的條件」。Speed Survival 贏在冷靜，CTF 贏在判斷，LAN 贏在比對手多想一步。不是誰活得久，是誰比較會玩。

**玩家需要做什麼新的判斷或操作？**

Speed Survival 你要決定「這口值不值得冒險吃」，因為速度只會越來越快。CTF 你要想「現在該去偷旗，還是先守家」，因為死掉會掉旗。LAN 你要讀懂對手在想什麼——人類會故意留破綻。Magnet 你要控制吸引範圍，不能讓食物擴散到滿版。修改器開了之後，連方向都不能靠習慣反應，要想著「現在是反的」。

**如果有使用 MediaPipe，它如何影響玩法？**

沒有使用 MediaPipe。不需要鏡頭或手勢辨識，因為這個版本的核心問題不是「怎麼操作」，而是「怎麼決定下一步」。

**我希望玩家玩完後覺得哪裡和普通 Snake 不一樣？**

希望他們覺得「原來 Snake 可以不用比誰最長」。每一次輸了不是因為「撞到自己」，而是因為「判斷錯了」——那顆食物不該吃的、那面旗不該去搶的、那個彎不該轉的。輸得有道理，比莫名撞死有意思多了。
